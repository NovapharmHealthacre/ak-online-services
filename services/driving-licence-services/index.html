Driving Licence Services

All Sarathi/RTO tasks from the supplied file: Learner's Licence, new DL, renewal/duplicate, name change, mobile update and address change.

Everything in this department

Nothing from the supplied Driving Licence document is collapsed or omitted: each workflow is now listed separately.

Driving Licence Workflows

  • Apply for Learner's Licence (LL) — Digital application filing, fee-payment guidance and online learner-test slot booking.
  • Apply for New Driving Licence (DL) — Assistance upgrading from Learner’s Licence to Permanent DL, including RTO track-test slot booking.
  • Driving Licence Renewal / Duplicate DL — Renewal assistance for expiring licences and replacement-filing support for lost, stolen or damaged cards.
  • Name Change in Driving Licence — Eligible spelling corrections, post-marriage surname changes or Gazette-supported legal-name changes.
  • Add / Change Mobile Number — Link or change the active mobile number used for RTO alerts and OTPs.
  • Address Change in Driving Licence — Update current permanent or residential address in the transport record.

Typical documents to bring

  • Aadhaar Card
  • Current Driving / Learner’s Licence where applicable
  • Blood Group report
  • Age proof
  • Address proof
  • Supporting Gazette / marriage document where applicable to a name change
Important: RTO testing, verification, eligibility, approval and licence issuance remain with the competent transport authority.
